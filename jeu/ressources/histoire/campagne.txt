# GET A JOB : la campagne. Le jeu lit ce fichier au lancement (histoire.LecteurCampagne).
# La logique de l'histoire, personnage par personnage et mission par mission, est expliquee dans jeu/NARRATION.md.
# Une instruction par ligne : "mot arguments | texte | texte". Une ligne qui commence par # est ignoree.
#
# LE QUARTIER
#   depart <carte> <x> <y>                                   ou commence une nouvelle partie
#   verrou <carte> | <NOM> | <phrase>                        lieu ferme, son nom, et ce qu'on lit devant la porte
#   voix <id> | <NOM> | <buste>                              quelqu'un qui parle sans etre pose dans le decor
#   timbre <id> <hauteur>                                    la hauteur de sa voix (1 = moyenne)
#   figurant <id> | <carte> <repere> <dx> <y> | <image> | <NOM> | <de> <a>
#       condition +drapeau -drapeau                          il n'est la que si les drapeaux le permettent
#       bavarde [+drapeau -drapeau] | <phrase>               ce qu'il dit quand l'histoire n'attend rien de lui
#       patrouille <distance> <vitesse>   garde <distance> <vitesse>   tourne (regarde a gauche)
#   point <id> | <carte> <repere> <dx> <y> | <image[:hauteur]> | <INVITE>
#   Un lieu se donne par rapport a un repere du decor ; "-" garde la hauteur du repere.
#   <de> <a> : premiere et derniere mission ou le personnage est la ; "fin" = une fois l'histoire jouee.
#
# L'HISTOIRE
#   chapitre <id> | <TITRE> | <SOUS-TITRE> | <accroche>
#   mission <id> | <TITRE> | <lieu> | <personnages>
#       resume | <description>      ouvre <carte> ...      debut <scene>      fin <scene>
#       meteo pluie|sec      musique <theme>      chrono <secondes>      furtive      repli <carte> <repere> <dx> <y>
#       objectif <parler|agir|aller|atteindre> <cible> [pression] [si +d -d] [musique:<theme>] [-> scene] | <TEXTE>
#       option   ... (meme forme)                            objectif secondaire, faisable a tout moment de la mission
#
# LES SCENES
#   cinematique <id>, puis des plans : carte, noir, recit, dit, choix, etiquette, saut, si, drapeau, acteur, pose,
#   regarde, retire, marche, camera, attend, effet, son, musique, ambiance, meteo, gros_plan, sms, annonce, titre,
#   carton, joueur. Sans plan "carte" ni "noir", la scene se joue sur place, avec les personnages presents.
#   Une position x peut citer un repere : @banc+20.
