# GET A JOB : la campagne. Le jeu lit ce fichier au lancement (histoire.LecteurCampagne).
# La logique de l'histoire, personnage par personnage et mission par mission, est expliquee dans jeu/NARRATION.md.
# Une instruction par ligne : "mot arguments | texte | texte". Une ligne qui commence par # est ignoree.
#
# LE QUARTIER
#   depart <carte> <x> <y>                                   ou commence une nouvelle partie
#   verrou <carte> | <NOM> | <phrase>                        lieu ferme, son nom, et ce qu'on lit devant la porte
#   voix <id> | <NOM> | <buste>                              quelqu'un qui parle sans etre pose dans le decor
#   vocal <id> <banque> [hauteur] [debit] [melodie]          sa voix : une banque de ressources/sons/voix, reglee
#   figurant <id> | <carte> <repere> <dx> <y> | <image> | <NOM> | <de> <a>
#       condition +drapeau -drapeau                          il n'est la que si les drapeaux le permettent
#       bavarde [+drapeau -drapeau] | <phrase>               ce qu'il dit quand l'histoire n'attend rien de lui
#       patrouille <distance> <vitesse>   garde <distance> <vitesse>   tourne (regarde a gauche)
#       routine poste|flane|assis|comptoir [rayon]   ce qu'il fait seul : rester, aller et venir, rester assis, tenir le comptoir
#       caractere fragile|costaud|police|proche          s'il fuit, riposte, intervient, ou encaisse mal (deduit du dessin sinon)
#       membre <id>                                       un petit de l'equipe : absent tant qu'il est sur une operation
#   point <id> | <carte> <repere> <dx> <y> | <image[:hauteur]> | <INVITE>
#   Un lieu se donne par rapport a un repere du decor ; "-" garde la hauteur du repere.
#   <de> <a> : premiere et derniere mission ou le personnage est la ; "fin" = une fois l'histoire jouee.
#
# L'HISTOIRE
#   chapitre <id> | <TITRE> | <SOUS-TITRE> | <accroche>
#   mission <id> | <TITRE> | <lieu> | <personnages>
#       resume | <description>      ouvre <carte> ...      debut <scene>      fin <scene>
#       quand <jour> <hh:mm>   le jour (1 = le premier vendredi) et l'heure ; plus de 6 h apres la mission d'avant : on se
#                              reveille chez soi ; l ecran du temps qui passe montre ce qui est arrive entre-temps
#       meteo pluie|sec      musique <theme>      chrono <secondes>      furtive      repli <carte> <repere> <dx> <y>
#       objectif <parler|agir|aller|atteindre> <cible> [pression] [si +d -d] [avec:<objet>] [argent:<n>] [musique:<theme>] [-> scene] | <TEXTE>
#           avec:<objet> : il faut l'avoir dans l'inventaire (une livraison : le sac) ; sinon l'objectif ne compte pas
#           argent:<n> : il faut avoir n euros sur soi (rembourser) ; sinon l'objectif ne compte pas. La scene paie.
#       option   ... (meme forme)                            objectif secondaire, faisable a tout moment de la mission
#
# LES SCENES
#   cinematique <id>, puis des plans : carte, noir, recit, dit, choix, etiquette, saut, si, drapeau, acteur, pose,
#   regarde, retire, marche, camera, attend, effet, son, musique, ambiance, mixage, meteo, gros_plan, sms, annonce, titre,
#   donne <objet> [n] [qui] : qui le tend, le heros le prend, il entre dans l'inventaire ; remet <objet> [n] [qui] : l'inverse
#   appel <qui> sonne <voix> | decroche | raccroche : son telephone sonne, il decroche (ses repliques et celles de <voix>
#       s'affichent comme un appel), il raccroche et revient a la conversation
#   conduite <parcours> <scene> : la scene rend la main, on prend le volant (jeu/Conduite.java), puis <scene> se joue
#   carton, joueur, temps <jour> <hh:mm> (l'horloge, pendant une ellipse), argent <+n|-n>, paie <n> <etiquette si l'argent manque>, soin <points>, loue <secondes>, message <qui> | <texte> | <réponse -> +drapeau> ... Sans plan "carte" ni "noir", la scene se joue sur place, avec les personnages presents.
#   Une position x peut citer un repere : @banc+20.
#   dit <qui>:<ton> | ...   le ton de la replique : joie, rire, colere, menace, triste, fatigue, peur, surpris, gene,
#       hesite, doute, insolent. Il change la voix et peut s'annoncer par un soupir, un "hm", une inspiration.
#   son <nom> [gain] [net]   net : le son reste net quand le mixage etouffe le monde.
#   mixage <normal|choc|sourdine|silence> [duree]   ce qu'on entend du monde : un choc l'etouffe, la scene suivante le rend.

cinematique intro
# Aucune parole, aucun texte. L'avenue sous la pluie, puis lui, de dos, devant sa tele : la seule lumiere de la piece.
# On ne voit jamais ce que la tele montre ; on voit ce que ca lui fait. Le plan large revient a la fin, la camera
# recule : il est seul. Gros plan : image, duree, zoom de depart, zoom d'arrivee, point vise (x y), [secousse], [coupe].
#
# Le son raconte la meme chose en quatre temps.
# Avant : la ville sous la pluie, ouverte ; puis dedans, la pluie derriere la vitre, la tele qui parle toute seule,
#   l'horloge. Rien d'inquietant. Une montee grave, presque inaudible, commence quand on voit ses yeux.
# Pendant : la tele crache, le presentateur bute sur un mot ; un coup sourd, il inspire d'un coup.
# Reaction : le monde s'etouffe d'un seul coup (la pluie, la tele, tout passe derriere un mur), un sifflement
#   remplace le reste ; on n'entend plus que son coeur. La cigarette qui tombe est le seul son net.
# Apres : la tele n'est plus que de la neige ; le monde revient lentement, pendant que la camera recule. Puis le
#   silence, un souffle, et il se tourne vers nous.
